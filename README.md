# 末日收件箱

一个浏览器可玩的反钓鱼生存小游戏 MVP。玩家先进入可点击的俯视像素基地，再通过指挥室处理一封“紧急物资领取”邮件，在接受、举报或隔离进沙盒之间作出选择。

## Phaser 基地场景

项目通过 Phaser v3.90.0 CDN 运行，不需要安装 Node.js。

- 开局只拥有指挥、通信、仓储、医疗与中继等基础设施；点击「指挥室」可打开收件箱。
- 菜园、净水设施和三处外围地块都以透明点击区预留在地图上，必须通过后续正确邮件判断取得蓝图、物资或施工权限后才能建设。
- 可切换白天/夜晚；夜晚会强化基地的危险感。
- 接受钓鱼邮件会让网络中继器在地图中变为受损。
- 举报成功会升级无线电站并获得情报。

基地现在使用 `assets/base-day.webp` 作为暖色俯视日间底图。Phaser 在建筑与预留地块对应位置放置透明交互区、昼夜遮罩、光照层和受损/升级标记；这让美术与玩法逻辑可以独立迭代。后续邮件只需调用 `unlockExpansion('garden')` 或 `unlockExpansion('water')`，即可把对应地块标为可建设。

下一步可继续把住民与状态标记替换为 16×16 像素 sprite，并加入独立的夜晚底图与 Tiled 地图数据。

## 本关威胁

攻击者使用了近似真实供应商的仿冒域名：

- 可信域名：`northrelief-logistics.co`
- 伪造域名：`north-relief-logistics.co`

玩家可以直接接受（触发凭证泄露）、举报，或先在沙盒中查看安全的模拟分析结果再举报。

## 运行

项目没有构建依赖。直接打开 `index.html`，或在项目目录运行：

```bash
python3 -m http.server 4173
```

然后访问 `http://localhost:4173`。
