# 末日收件箱

一个浏览器可玩的反钓鱼生存小游戏 MVP。所有界面都直接绘制在 Phaser 游戏画布内：玩家在俯视基地中点击指挥室，再通过游戏内终端处理邮件、沙盒和举报台。

## Phaser 基地场景

项目通过 Phaser v3.90.0 CDN 运行，不需要安装 Node.js。

- 开局只拥有指挥、通信、仓储、医疗与中继等基础设施；点击「指挥室」可打开收件箱。
- 菜园、净水设施和三处外围地块都以透明点击区预留在地图上，必须通过后续正确邮件判断取得蓝图、物资或施工权限后才能建设。
- 可切换白天/夜晚；夜晚会强化基地的危险感。
- 接受钓鱼邮件会让网络中继器在地图中变为受损。
- 举报成功会升级无线电站并获得情报。

基地现在使用 `assets/base-day.webp` 作为暖色俯视日间底图。Phaser 同时负责地图、资源 HUD、游戏内终端、透明交互区、昼夜遮罩与受损/升级标记；HTML 只保留游戏挂载点。

下一步可继续把住民与状态标记替换为 16×16 像素 sprite，并加入独立的夜晚底图与 Tiled 地图数据。

## 本关威胁

攻击者使用了近似真实供应商的仿冒域名：

- 可信域名：`waterworks.org`
- 伪造域名：`waterworkss.org`

玩家可以直接接受（触发凭证泄露）、举报，或先在沙盒中查看安全的模拟分析结果再举报。

## 运行

项目没有构建依赖。直接打开 `index.html`，或在项目目录运行：

```bash
python3 -m http.server 4173
```

然后访问 `http://localhost:4173`。

## 事件规则（进行中）

- 事件卡位于 `events.js`：仿冒来源会对应一个可信来源档案，而不是使用无关机构。
- 邮件线索默认隐藏；玩家可花金币进行一次外部核验。
- 沙盒每天只有一次额度，并且只分析链接或附件等数字载荷。
- 合法物资邮件被拒绝不会直接扣数值，但至少三天后才可能再次出现；未付款的市场订单会使该商家暂时停止交易。
- 夜间先结算白天泄漏信息导致的必然人为后果，再以 70% 概率判定改造人袭击。
- 建设设施需要蓝图、组件、劳动力和材料；事件卡只会逐步提供这些条件。
